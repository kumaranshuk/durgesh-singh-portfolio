Photo Manager

Upload and change every photo on the website. Simple — pick a photo, click Upload. Not connected

1 Connect to GitHub (one time)

Need a token? Open GitHub → Fine-grained tokens, set Repository access to only this repo, and under Permissions → Repository → Contents choose Read and write. Copy the token here. Your token is stored only in this browser, never uploaded anywhere except GitHub's own API.

2 Change photos

Each card below is one photo on the website. Choose an image and click Upload. Large phone photos are automatically resized so the site stays fast. Changes appear on the live site within a minute.
